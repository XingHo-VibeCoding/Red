# 红军长征叙述性网站 · 运行说明（Day 7 MVP / Day 8 数据驱动 / Day 10 插画升级）

> 这是 v1 MVP 的运行存档。当前形态（Day 10 起）：**主 `index.html` + `assets/` 素材文件夹**，代码零依赖、零安装。运行方式不变：双击 `index.html`。

## 怎么运行（当前方式，2026-09-21 拍板）

1. 打开文件夹 `red-army-story/`；
2. **双击 `index.html`**，用浏览器（推荐 Chrome / Edge）打开；
3. 进入引导页 → 点「开始体验」（这一下同时解锁背景音乐）→ 之后**纯滚动推进**，全程无需再点击。

> 就这么简单——不需要装任何东西、不需要起服务、不需要联网（BGM 是浏览器现场合成的，没有音频文件）。

## 打开后怎么玩

| 操作 | 效果 |
|---|---|
| 鼠标滚轮往下滚 | 故事一幕幕推进（围 → 出发 → 湘江 → … → 会师），共十幕 |
| 右上角「🔊 音乐：开/关」 | 静音 / 恢复背景音乐 |
| 左下角「🗺」按钮 | 弹出行军地图：长征路线随滚动从瑞金描金到会宁，显示"当前位置" |
| 滚到最底 | 收尾升华段（"我们正走在他们换来的今天里"） |
| 右下角小金字 | 史实口径标注（v1 文案待逐条核实） |

> 系统"减少动态效果"开启时，动画自动收束，内容照常可读（PRD §5 可访问性）。

## Day 8 更新：数据驱动 + 四种页面状态

十幕文案不再写死在页面里，而是抽成脚本内的 **`SCENES` 假数据数组**，页面打开时由它渲染每一幕（幕=卡片、幕序列=列表；未来接真实 API 只需把数组换成接口数据，视觉零改动）。配套四种页面状态：

| 状态 | 什么时候出现 | 你会看到 |
|---|---|---|
| 加载态 | 页面刚打开的半秒 | 金色转环 + "正在铺开画卷…"，随后自动消失 |
| 正常态 | 数据渲染成功 | 十幕叙事照常 |
| 空态 | 数据为空 | "内容筹备中——叙事画卷暂无数据"，不白屏 |
| 错误态 | 渲染出错 | 兜底提示 + 「重新加载」按钮，不白屏 |

## Day 10 更新：视觉风格重构（第一幕验证）+ 素材文件夹

- 第柒幕（泸定桥）的剪影场景替换为 **AI 生成的正形纹样插画**（暗底红金色盘 + 繁密民俗纹样，经两轮 prompt 迭代定稿），动效（慢推拉、文字揭示）叠加在插画上，其余九幕暂未动。
- **单文件原则退役**（PRD §6 已修订）：插画等大素材放 `assets/` 文件夹，`index.html` 通过相对路径引用——**整个 `red-army-story/` 文件夹要一起拷贝/提交，别只拷 html**。
- `assets/luding-bridge.png` —— 泸定桥幕插画素材。

## 将来如果要 localhost 方式（备用，现在不需要）

截图要求地址栏是 `localhost` 开头时，或以后项目变大需要本地服务器时，任选其一：

```bash
# 方式一：Python 内置静态服务器（电脑装了 Python 即可）
cd red-army-story
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 方式二：Node 静态服务器
npx serve red-army-story
```

> 当前 MVP 双击即可，以上命令仅备用存档。
