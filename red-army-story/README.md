# 红军长征叙述性网站 · 运行说明（Day 7 MVP）

> 这是 v1 MVP 的运行存档。当前形态：**单文件纯前端**（`index.html` 一个文件含全部内容），零依赖、零安装。

## 怎么运行（当前方式，2026-09-21 拍板）

1. 打开文件夹 `red-army-story/`；
2. **双击 `index.html`**，用浏览器（推荐 Chrome / Edge）打开；
3. 进入引导页 → 点「开始体验」（这一下同时解锁背景音乐）→ 之后**纯滚动推进**，全程无需再点击。

> 就这么简单——不需要装任何东西、不需要起服务、不需要联网（BGM 是浏览器现场合成的，没有音频文件）。

## 打开后怎么玩

| 操作 | 效果 |
|---|---|
| 鼠标滚轮往下滚 | 故事一幕幕推进（围 → 出发 → 湘江 → … → 会师），共十幕 |
| 右上角「🔊 音乐：开/关」 | 静音 / 恢复背景音乐 |
| 左下角「🗺」按钮 | 弹出行军地图：长征路线随滚动从瑞金描金到会宁，显示"当前位置" |
| 滚到最底 | 收尾升华段（"我们正走在他们换来的今天里"） |
| 右下角小金字 | 史实口径标注（v1 文案待逐条核实） |

> 系统"减少动态效果"开启时，动画自动收束，内容照常可读（PRD §5 可访问性）。

## 将来如果要 localhost 方式（备用，现在不需要）

截图要求地址栏是 `localhost` 开头时，或以后项目变大需要本地服务器时，任选其一：

```bash
# 方式一：Python 内置静态服务器（电脑装了 Python 即可）
cd red-army-story
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 方式二：Node 静态服务器
npx serve red-army-story
```

> 当前 MVP 双击即可，以上命令仅备用存档。
